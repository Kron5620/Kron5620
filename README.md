### What I’m building

[MCMarket](https://mcmarket.org/) is a simple Minecraft marketplace featuring market scanning, checkout, and Discord integrations, with support for some of the largest Minecraft servers.

The stack includes **JavaScript, HTML, CSS, Node.js, MySQL, Three.js, WebSockets, Mineflayer, discord.js and esbuild**.
